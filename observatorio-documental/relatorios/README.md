# Relatorios Automatizados

Os relatorios diarios nao sao commitados nesta pasta. Eles aparecem em cada execucao do workflow **Auditoria documental diaria** como:

- resumo da execucao no GitHub Actions;
- artefato `auditoria-documental-AAAA-MM-DD`, retido por 30 dias.

Essa politica evita commits diarios sem revisao e preserva o historico tecnico no local em que ele foi produzido.
