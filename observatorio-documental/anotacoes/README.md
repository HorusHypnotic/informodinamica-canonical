# Anotacoes do Observatorio

Use esta pasta para registrar fatos verificaveis, perguntas e inconsistencias encontradas no acervo.

Cada anotacao deve informar:

- data;
- autor ou agente;
- documentos observados;
- fato ou conflito encontrado;
- evidencia local com caminho e secao;
- impacto possivel;
- proxima decisao humana.

Uma anotacao nao altera o documento observado nem recebe autoridade canonica por estar versionada.
