# Insights Candidatos

Use esta pasta para interpretacoes derivadas da leitura cruzada do acervo.

Todo insight deve distinguir explicitamente:

- observacao documentada;
- inferencia;
- hipotese ou proposta;
- documentos de origem;
- contradicoes conhecidas;
- criterio necessario para validacao ou rejeicao.

Insights permanecem candidatos. Sua promocao segue `docs/workflow.md`, `protocols/PRT-001-ciclo-de-vida.md` e, quando houver fundamento externo, `protocols/PRT-002-cartografia-epistemologica.md`.
