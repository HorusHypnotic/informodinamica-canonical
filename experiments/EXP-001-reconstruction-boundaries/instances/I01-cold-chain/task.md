# I01 — Despacho de carga térmica sintética

**Momento de retomada:** 10:20 de 18/09/2031

Uma central logística sintética deve despachar dois contentores térmicos para o Posto N-4 até 14:00. A tarefa do receptor é reconstruir o estado e escolher somente a primeira ação. Nenhum sistema externo ou conhecimento de logística é necessário.

Elementos de projeto: objetivo verificável, atualização temporal de liberação, dois veículos, dependência pré-despacho, rota vinculante, limite de autoridade, carga concluída, despacho pendente e bloqueio documental.
