# Checklist pré-run

- [ ] tag aponta ao commit congelado;
- [ ] fixture sem alterações locais;
- [ ] package ID e SHA-256 conferem;
- [ ] prompt SHA-256 confere;
- [ ] mapa selado inacessível ao receptor;
- [ ] sessão completamente nova;
- [ ] sem memória ou histórico;
- [ ] somente `prompt.md` e `record.md` preparados;
- [ ] produto/modelo/modo iguais ao manifesto;
- [ ] versão visível registrada ou limitação confirmada;
- [ ] ferramentas disponíveis iguais ao manifesto;
- [ ] ambiente base restaurado;
- [ ] log pré-run criado antes do envio;
- [ ] nenhum STOP ativo;
- [ ] autorização humana final registrada.

Sem todos os itens, não enviar ao receptor.
