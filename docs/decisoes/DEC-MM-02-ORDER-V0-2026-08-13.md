# DEC-MM-02 — Customer + Order V0

**Data:** 2026-08-13
**Resultado:** YELLOW — núcleo implementado; produção retida

## Decisão

Adotar Customer, Order, Offer Snapshot e OrderEvent mínimos conforme `commercial/schemas/order-v0.schema.json`. Usar Supabase Edge Function + PostgreSQL/RLS como backend candidato por coerência com a integração já existente, sem declarar que o projeto atual possui tenancy, ownership ou segurança aprovados.

A versão candidata da oferta é 1.1.0, `APPROVED`, `order_enabled=false`, com SLA e correção factual decididos nesta missão. A versão pública V1.0.0 não muda. A candidata só se torna `ACTIVE/order_enabled=true` pela aplicação controlada da migração e publicação posterior do snapshot/storefront.

## Motivo para não implantar

Não há Supabase CLI, vínculo local de projeto, credenciais ou confirmação versionada de tenancy/ownership. Implantar em um endpoint inferido violaria o gate de segurança e poderia alterar infraestrutura de terceiro ou produção não governada. O storefront não será enviado com formulário que sugira persistência inexistente.

## Consequência

O domínio, API, banco, UI, confirmação, owner lookup e dogfood sintético estão implementados/testados em código. O sistema ainda não está `READY FOR FIRST REAL ORDER`; falta um Deployment Gate com acesso autorizado à infraestrutura. Nenhum Customer ou Order real foi criado.
