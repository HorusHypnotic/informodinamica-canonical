# MET-007 — Protocolo de Patologia da Coordenação (Análise de Colapso)

**Status:** Estável / Fundamental

## Definição

O MET-007 estabelece o protocolo para **diagnosticar a degradação e o colapso da coordenação**. Funciona como uma autópsia metodológica para compreender como um sistema coordenativo adoece, perde acoplamento e falha.

## Fases de Análise Patológica

A investigação de falhas de coordenação obedece a uma progressão analítica rigorosa:

- **Fase 0: Estado Canônico Esperado** — Mapeamento do funcionamento ideal conforme prescrito pelos protocolos e pela teoria, estabelecendo a linha de base de baixa entropia.
- **Fase 1: Onde a coordenação se rompeu?** — Identificação precisa do nó crítico ou interface entre agentes onde a ação esperada deixou de ocorrer.
- **Fase 2: Qual representação falhou primeiro?** — Classificação da falha informacional em categorias fundamentais: perda de dados, atraso na transmissão, ambiguidade semântica, conflito de representações ou excesso de carga cognitiva.
- **Fase 3: Qual foi o primeiro sintoma observável?** — Detecção do sinal precursor que antecedeu o colapso sistêmico.
- **Fase 4: Como a degradação se propagou?** — Mapeamento da cascata de erros através das dependências do sistema.
- **Fase 5: Qual representação poderia ter interrompido a cascata?** — Formulação contrafactual para identificar o mecanismo de recalibração ausente.

## Uso

O MET-007 é aplicado a incidentes, falhas operacionais e quase-acidentes, utilizando a linha de base do MET-006 para quantificar o desvio informodinâmico e gerar prescrições para o MET-008.
