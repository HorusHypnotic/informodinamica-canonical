# MET-009 — Protocolo de Validação Veridical e Calibração

**Status:** Estável / Transversal

## Definição

O MET-009 estabelece o protocolo para avaliar, medir e projetar a *recalibração* de sistemas coordenativos. Ele não trata a validação como uma etapa final, mas como uma camada epistemológica contínua que perpassa toda a análise.

## Premissas

1. Toda representação persistente tende a desacoplar-se progressivamente do fenômeno que representa, salvo quando mecanismos explícitos de recalibração atuam continuamente sobre ela.
2. A recalibração exige uma *fronteira operacional* entre representação e fenômeno, por onde novos sinais possam entrar no sistema.
3. A resiliência epistêmica não nasce de um calibrador infalível, mas de uma arquitetura onde nenhum canal isolado possui monopólio sobre a correção.

## Modalidades

### MET-009A — Calibração Assistida
A revisão depende de uma ação externa deliberada (ex: inspeção humana, auditoria agendada).

### MET-009B — Calibração Incorporada
A própria arquitetura do sistema contém:
1. Sinais de desacoplamento;
2. Gatilhos de revisão;
3. Acesso a novas observações;
4. Regras de atualização;
5. Registro da correção;
6. Possibilidade de intervenção humana.

## Grandezas fundamentais (Latências)

Para o MET-009B, define-se o ciclo de recalibração a partir de cinco instantes:
- **T₀** — Desacoplamento (mundo muda, representação não)
- **T₁** — Evidência disponível
- **T₂** — Detecção da divergência
- **T₃** — Início da ação corretiva
- **T₄** — Restauração do acoplamento

As latências resultantes são:
- Observação (T₁ - T₀)
- Detecção (T₂ - T₀)
- Resposta (T₃ - T₂)
- Restauração (T₄ - T₃)
- Total (T₄ - T₀)

## Aplicação

Este método é transversal aos MET-006, 007 e 008. Todo diagnóstico, projeto ou análise deve ser interrogado pelo MET-009:
> *"Qual o erro atual desta representação? Qual a tendência desse erro? Quando ele ultrapassará o limiar de tolerância?"*
