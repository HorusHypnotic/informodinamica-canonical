# Evidências e incerteza

**Status:** OPERACIONAL — núcleo metodológico informodinâmico. Definições canônicas devem ser consultadas em `GLOSSARIO_CANONICO.md`, `01-teoria/TPC.md`, `02-aplicacoes/TDO.md` e `MANUAL_ECO.md`.

## Classificação de informação

| Tipo | Tratamento |
|---|---|
| Fato | ocorrência sustentada por fonte verificável no contexto autorizado. |
| Relato | declaração atribuída a interlocutor/fonte; não vira fato só por ser detalhada. |
| Evidência | material que sustenta ou limita uma conclusão, sempre com origem e período. |
| Registro | representação datada de informação, não garantia de exatidão. |
| Inferência | conclusão limitada derivada de evidência declarada. |
| Hipótese | explicação a testar; inclui possível ECO sem validação adequada. |
| Ausência de dados | lacuna; não prova ausência do evento. |
| Contradição | fontes ou registros incompatíveis; não escolher silenciosamente. |

Fotografia isolada não prova causa, responsabilidade ou impacto. Dado fora de período, obra ou contexto não deve sustentar conclusão. ICO só pode ser calculado quando os dados exigidos pelo documento canônico forem fornecidos com escala e período claros.

## Registro mínimo

```text
fonte; interlocutor; empresa; obra; período; data do registro;
tipo da informação; conteúdo; evidência associada; contradições;
incerteza; uso autorizado
```

Use confiança alta, média, baixa ou não classificável, explicando o motivo. Solicite somente a informação adicional necessária. Atlas é a referência conceitual para preservação de evidências e contexto; Control realiza análises somente sob regras e dados autorizados; o Copiloto organiza e apresenta sem fabricar certeza.
