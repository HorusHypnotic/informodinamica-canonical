# Escopo do RP-001

## Este pacote NÃO pretende:
- Validar definitivamente a TPC;
- Propor uma teoria geral da coordenação;
- Substituir métodos existentes de análise de sistemas;
- Apresentar resultados empíricos conclusivos sobre domínios reais.

## Este pacote pretende:
- Descrever uma metodologia explícita para análise da persistência da coordenação;
- Documentar um laboratório reproduzível (EXP-001) com dados observáveis;
- Tornar explícitos pressupostos, evidências e limitações;
- Oferecer um framework testável para futuras replicações e validações.
