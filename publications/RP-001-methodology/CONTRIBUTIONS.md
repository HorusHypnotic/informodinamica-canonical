# Contribuições do RP-001 – Metodologia para Análise da Persistência da Coordenação

Este Research Package entrega cinco contribuições fundamentais para a literatura de sistemas sociotécnicos: uma metodologia explícita (MET-006 a MET-009), um laboratório reproduzível (EXP-001), uma arquitetura de governança conceitual, um protocolo para evolução de teorias e um modelo de publicação versionada.
