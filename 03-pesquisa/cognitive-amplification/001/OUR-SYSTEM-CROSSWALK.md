# OUR-SYSTEM-CROSSWALK.md

O caso `humano → ChatGPT → Manus/Codex → evidência → Git → Control Tower → nova decisão` é **OBSERVAÇÃO**, não prova.

| Elemento observado | Constructo externo sobreposto | O que não demonstra |
|---|---|---|
| curiosidade/busca | exploration, network access, absorptive capacity | capacidade geral |
| acesso a ChatGPT/Manus/Codex | external cognition, transactive systems | confiabilidade automática |
| teste/erro | experimentation, feedback learning | causalidade do loop |
| Git/Markdown | external memory, distributed cognition | compreensão ou retenção humana |
| Control Tower | organizational memory, coordination | autonomia global |
| nova decisão | transfer/adaptation | generalização fora do caso |

O crosswalk indica sobreposição funcional, não equivalência. O caso tem forte risco de seleção, ausência de denominador e confusão entre processo documental e capacidade cognitiva.
