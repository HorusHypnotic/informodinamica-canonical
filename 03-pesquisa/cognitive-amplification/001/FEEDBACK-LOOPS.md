# FEEDBACK-LOOPS.md

O loop operacional mais defensável é `IDEA → ACTION → FEEDBACK → ERROR → UPDATE → NEXT ACTION`. Há precedentes em aprendizagem organizacional, experimentação, OODA, active learning, software engineering e ciência, mas “retroalimentação cognitiva” não é um constructo padrão único.

| Elemento | Medida potencial | Critério de capacidade |
|---|---|---|
| idea | hipótese versionada | não basta registrar ideia |
| action | execução com timestamp | separar intenção de ação |
| feedback | resultado independente | não usar avaliação circular |
| error | divergência pré-especificada | erro precisa ser observável |
| update | mudança verificável | distinguir retórica de mudança |
| next action | ação nova adequada | transferência/adaptação |

Velocidade só é útil se o feedback for válido e o loop não amplificar erro. A melhor operacionalização futura é longitudinal e baseada em logs mais avaliação humana independente.
