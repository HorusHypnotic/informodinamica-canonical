# TRANSFER-RETENTION-EVIDENCE.md

Learning science supports delayed tests and transfer as separate outcomes. Retrieval and spacing improve long-term memory, but transfer depends on similarity, abstraction and task design [1] [2]. Worked examples and cognitive apprenticeship can support schema acquisition, but external support must be faded and independent performance tested.

| Pattern | Verdict |
|---|---|
| PRE → intervention → POST | sufficient for immediate learning, not capacity alone |
| POST → near transfer | useful but weak generalization |
| POST → far transfer | strongest transfer evidence, difficult and heterogeneous |
| delayed retention | required for persistence |
| adaptation to changed environment | required for flexible capability |
| independent performance after support removal | distinguishes capability from dependence |

Best public candidate: OULAD has longitudinal assessments and prior performance but no clean external intervention or novel-task transfer. Offloading studies have delayed memory but narrow tasks. No candidate found that cleanly covers all seven stages.
