# EXTERNALIZATION-OFFLOADING.md

External tools often improve immediate performance by shifting memory or computation outside the person. The offloading experiment found higher immediate efficiency but lower subsequent memory under unconstrained offloading [6]. This is a direct negative control against assuming that performance augmentation equals capability acquisition.

| Tool | Immediate gain | Residual learning question | Failure mode |
|---|---|---|---|
| writing/notes | preserve information | recall without notes | shallow encoding |
| calculator | arithmetic accuracy | conceptual transfer | dependence |
| GPS/search | navigation/retrieval | route/model retention | deskilling/overload |
| notebooks/Git | external memory/versioning | independent reconstruction | stale or copied state |
| AI assistant | text/code/decision support | removal, transfer, calibration | automation bias |

The tool changes the system only if interaction, feedback, representation and practice change.
