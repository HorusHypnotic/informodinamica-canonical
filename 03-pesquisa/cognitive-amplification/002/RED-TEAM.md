# RED-TEAM.md

Could all apparent amplification be explained by prior intelligence, schooling, resources, motivation, selection, experience or capital? Often yes unless these are measured and controlled.

| Explanation | Control/data requirement | Best candidates | Residual concern |
|---|---|---|---|
| prior ability | baseline task and pretest | learning RCTs, OULAD | measurement error |
| schooling/domain expertise | education, expertise, task history | OULAD, medical study | selection/confounding |
| resources/access | demographic/context and allocation | RCTs | external validity |
| motivation/persistence | pre/post motivation, effort, dropout | Liu preprint, learning studies | self-report bias |
| selection/survivorship | full cohort and failures | OULAD, GitHub events | missing unobserved population |
| task difficulty | randomized/equated novel tasks | RCTs | ecological validity |
| capital/infrastructure | organization and project controls | science/software data | hard to separate from network |

No mechanism is declared independent when these explanations are not separable.
