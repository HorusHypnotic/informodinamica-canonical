# NEGATIVE-EVIDENCE.md

| Negative pattern | Source/candidate | Classification | Interpretation
|---|---|---|---|
| offloading improves immediate task but reduces later memory | Grinschgl et al. [6] | CONTRADICTORY / CONTEXT_DEPENDENT | efficiency–retention trade-off |
| AI assistance followed by lower independent performance | Liu et al. [7] | CONTRADICTORY | dependence signal; preprint status |
| network size without information diversity | network literature [9] | NO_EFFECT/CONTEXT_DEPENDENT | size is weak proxy |
| diversity without integration | absorptive capacity [10] [11] | CONTEXT_DEPENDENT | access is not assimilation |
| collaboration process can vary with task/environment | CI process literature [3] [13] | CONTEXT_DEPENDENT | group better is not capability acquisition |
| protocol exists without outcome | Chen et al. [4] | UNKNOWN | do not treat planned RCT as result |

Required controls include no-transfer, failed-transfer, automation bias, deskilling, overreliance, collaboration cost, network overload, information overload, negative transfer, expertise rigidity and feedback failure.
