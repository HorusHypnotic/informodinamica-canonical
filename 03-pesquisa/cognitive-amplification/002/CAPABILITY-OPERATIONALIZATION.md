# CAPABILITY-OPERATIONALIZATION.md

`INFORMATION_ACQUIRED` means information becomes available or recall improves in the trained context. `CAPABILITY_ACQUIRED` requires a pre-registered state change that persists after support removal and appears in a new or changed task.

Minimum evidence: baseline; exposure; immediate performance; delayed retention; near/far transfer; independent performance; adaptation; and error reduction relative to control. A single post-test is not enough.

| Claim | Required observation | Candidate status
|---|---|---|
| augmentation | assisted performance > control | measurable in several Human–AI studies |
| learning | post-removal > own baseline/control | emerging, but sparse |
| transfer | new-task performance > control | rare/partial |
| retention | delayed performance persists | available in learning/offloading studies |
| adaptation | changed environment handled | rarely measured |
| independence | performance remains without tool | direct in Liu preprint, needs validation |

No proprietary score should be created. Use established outcomes and report the full sequence.
