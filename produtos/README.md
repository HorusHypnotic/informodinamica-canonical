# Produtos do Ecossistema OPERA

**Em uma frase:** infraestrutura de interação, evidência, diagnóstico e integração para representações operacionais rastreáveis.

**Estado documental:** `ACTIVE`

O ecossistema OPERA é uma implementação candidata da TPC e da TDO. Seus produtos não validam a teoria por si sós e não substituem responsáveis humanos, técnicos ou legais.

## Fronteira de autoridade

- Os repositórios dos produtos são fontes operacionais de código e deploy.
- Este repositório preserva teoria, governança, documentação ativa, contratos e snapshots revisados.
- “Sincronizado” descreve a relação GitHub ↔ Lovable do produto; não significa sincronização automática com o canônico.
- Documentos históricos permanecem como evidência e não devem ser usados para substituir as definições ativas.
